# ShopEase - Product Showcase

**ShopEase** is a clean, modern, and responsive e-commerce landing page designed to showcase products in an attractive and user-friendly way. This project uses HTML and CSS and includes a hero section, featured products, about and contact sections, and interactive buttons.

---

## 🌟 Features

- **Responsive Design:** Works on desktop, tablet, and mobile devices.  
- **Hero Section:** Engaging gradient background with a "Shop Now" button.  
- **Products Section:** 16 products with "Order Now" buttons.  
- **About Section:** Brief description of ShopEase.  
- **Contact Section:** Contact information with email, phone, and address.  
- **Hover Effects:** Interactive buttons and product cards.  
- **Navigation:** Sticky navbar with smooth scroll to sections.  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
